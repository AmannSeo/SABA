KISA 보호나라에 따르면 Apache 재단은 자사 제품에서 발생하는 여러 보안 취약점을 해결한 보안 업데이트를 발표했다. 이 업데이트는 Apache HTTP Server에서 발생하는 다양한 취약점을 포함하고 있으며, 영향을 받는 버전을 사용하는 사용자에게는 최신 버전으로의 업데이트가 권고된다. 주요 취약점으로는 NULL Pointer Dereference, Exposure of Sensitive Information, Missing Authentication for Critical Function 등이 있다.
