3. 현재 확보된 것 vs 남은 것

현재 확보

  • CERT-EU RSS 수집 경로
  • Article 정규화·안정 ID·중복 처리 기반
  • AnalysisResult v1 및 검증 구조
  • AI 없이도 가능한 Newsletter 경로
  • 동적 Newsletter Template 및 Preview
  • 승인된 v09 Newsletter 디자인
  • 보호 원본·Secret·테스트 Harness 규칙

앞으로 남음

  • Provider 독립 AI Adapter Mock 검증
  • 외부 AI API Provider·Model 비교 및 선정
  • 실제 AI API TEST와 실제 뉴스 품질 검증
  • CERT-EU 외 뉴스 소스 확대
  • Notion 실제 연동
  • 회사 메일 TEST 및 실제 발송
  • HTML Email 호환성 검증
  • Scheduler와 24시간 실행 환경
  • 운영용 Admin UI와 운영 로그

4. AI 현재 방향

항목현재 상태
AI 필수 여부필수 아님. 실패하거나 사용하지 않아도 비AI 경로 유지.
방식외부 AI API 우선. Local LLM / Open-weight 직접 서버 운영은 현재 범위에서 제외.
Provider / Model아직 미선정. 14단계에는 선택할 필요 없음.
14단계Provider 독립 Adapter + Mock 검증. 실제 Network 요청 없음.
후속 선정무료 한도·비용·데이터 정책·한국어 적합성·구조화 출력·운영 난이도 등을 비교 후 승인.

5. Newsletter 예시 시안 — v09

현재 프로젝트에 보관된 v09 HTML/CSS/LOGO를 이 문서 안에 포함해 바로 볼 수 있도록 구성했다. 원본 파일은 수정하지 않았다.

6. 앞으로의 큰 흐름

14. AI Adapter Mock→AI API 비교·선정→실제 API TEST→뉴스 소스 확대→Notion / 검토→메일 TEST→Scheduler / 배포
회의용 큰 흐름이며, 아직 승인되지 않은 Provider·Model·메일 방식·배포 환경을 확정한 것은 아니다.

7. 회의에서 한 문장으로 설명

SABA는 보안·AI 뉴스를 자동 수집해 필요한 정보를 정리하고 HTML Newsletter를 만든 뒤 회사 메일로 매일 자동 배포하는 시스템이며, 현재 수집·분석 데이터 구조와 Newsletter 생성 기반까지 구축했고 실제 AI·메일·Scheduler 연결을 남겨두고 있습니다.
